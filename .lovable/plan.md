# שיפוץ UX — תבניות פרוטוקולים

המסך הנוכחי מחייב מעבר בין שני טאבים ("ברירות מחדל לחברה" / "שיוך לדומיין"), לא מציג רשימה של התבניות שכבר הוגדרו, ואין בו פעולה ברורה של "הוסף פרוטוקול". במקום זה — מסך דו-עמודי עם עץ שיוך משמאל ועורך מלא מימין.

## המבנה החדש

```text
┌───────────── עורך התבנית ─────────────┬──── עץ שיוך ────┐
│ כותרת + תגית (התאמה אישית / יורש מ..) │ 🔍 חיפוש         │
│ [תצוגה מקדימה] [שחזר] [שמור]          │ ▸ חברה (ברירות)  │
│                                        │   • מסירת ציוד ✓ │
│ כותרת הפרוטוקול │ תוקף (ימים)          │   • רכב          │
│ ─────────────────────────────────────  │ ▸ פיזי           │
│ טקסט הפרוטוקול (עם צ'יפים להוספת       │   ▸ מחשבים ✓     │
│ שדות דינמיים בלחיצה)                   │     • ניידים     │
│ ─────────────────────────────────────  │ ▸ רכב            │
│ [ ] דורש חתימת נותן הציוד              │ [+ פרוטוקול חדש] │
└────────────────────────────────────────┴──────────────────┘
```

- **עמודה ימנית (עץ שיוך):** דומיין ← קטגוריה ← תת-קטגוריה, בתוספת ענף "ברירות מחדל לחברה" בראש. כל צומת שיש לו תבנית מסומן בתגית "מותאם"; שאר הצמתים מוצגים בעמעום עם "יורש". חיפוש חופשי מסנן את העץ.
- **עמודה שמאלית (עורך):** אותם שדות של היום, אך תמיד גלויים במלואם ללא גלילה בין כרטיסים. במובייל: העץ נפתח כ-Sheet מלמטה, והעורך תופס את כל הרוחב.

## הוספת פרוטוקול חדש

כפתור "פרוטוקול חדש" פותח דיאלוג קצר:
1. **סוג פרוטוקול** — מתוך ששת הסוגים הקיימים.
2. **יעד שיוך (חובה)** — בחירה אחת מתוך: כל החברה / דומיין+קטגוריה / דומיין+קטגוריה+תת-קטגוריה. לא ניתן לשמור בלי לבחור יעד.
3. **בסיס** — התחלה מהתבנית שיורשים ממנה (ברירת מחדל) או מטקסט ריק.

בשמירה נוצרת התבנית, העץ קופץ לצומת החדש והעורך נפתח עליו. אם כבר קיימת תבנית לאותו סוג+יעד, הדיאלוג מציג התראה ומציע לעבור לעריכה במקום ליצור כפילות.

## שיפורים נוספים בעורך

- צ'יפים של שדות דינמיים (`{{employee_name}}` וכו') הופכים ללחיצים — לחיצה מכניסה את השדה למיקום הסמן בטקסט.
- אינדיקציה ברורה של מקור הירושה + כפתור "שחזר לברירת מחדל" רק כשקיימת התאמה אישית.
- שמירה מושבתת כשאין שינוי; אזהרה לפני יציאה מצומת עם שינויים שלא נשמרו.
- מחיקת תבנית ישירות מהעץ (תפריט הקשר), עם אישור.
