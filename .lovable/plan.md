# ארכיון מסמכי ביטוח בעת חידוש

## המצב היום
בחידוש תוקף (RenewExpiryDialog) ניתן להחליף קובץ מסמך — אבל ההחלפה דורסת את רשומת המסמך הקודמת: הקובץ הישן נשאר יתום באחסון, ואין שום עקבות לפוליסה של השנה הקודמת. אין מושג "תיקיית שנה" או ארכיון.

## ההצעה
בחידוש ביטוח, מסמכי השנה הקודמת לא נדרסים אלא עוברים אוטומטית לארכיון שנתי:

```text
כרטיס ביטוח
├── מסמכים נוכחיים (פוליסה 2026/2027)
└── ארכיון (מכווץ)
    ├── 2025/2026 — פוליסה, רישיון...
    └── 2024/2025 — ...
```

## מה נבנה
1. **שדה תקופה במסמכים** — לכל מסמך נכס (`asset_documents`) יתווסף שדה `period` (למשל "2025/2026") ודגל `is_archived`. ברירת מחדל: המסמכים הקיימים מסומנים כנוכחיים.
2. **חידוש = ארכוב אוטומטי** — כשמחדשים ביטוח ומעלים פוליסה חדשה, המסמכים הקיימים של אותו סוג מועברים לארכיון עם תווית התקופה שהסתיימה (נגזרת מתאריך התפוגה הישן), והקובץ החדש נשמר כנוכחי. אין מחיקה — הכול נשמר.
3. **תצוגה בכרטיס הנכס** — אזור המסמכים מחולק ל"נוכחיים" ול"ארכיון" מכווץ, מקובץ לפי תקופה, עם אפשרות לפתוח/להוריד כל מסמך מהארכיון.
4. **יומן פעילות** — כל ארכוב נרשם ביומן ("מסמך X הועבר לארכיון 2025/2026").
5. **ידני גם** — כפתור "העבר לארכיון" / "שחזר מארכיון" על כל מסמך, למקרים שלא דרך חידוש.

## פרטים טכניים
- מיגרציה: `ALTER TABLE asset_documents ADD COLUMN period text, ADD COLUMN is_archived boolean NOT NULL DEFAULT false` + GRANTs לפי הצורך.
- שינויים ב-`RenewExpiryDialog.tsx` (ארכוב במקום דריסה), ברכיב המסמכים של כרטיס הנכס (חלוקה נוכחי/ארכיון), ובשאילתות הרלוונטיות.
- לא נוגע בקבצים קיימים באחסון — רק מטא-דאטה.
- תאריכים בפורמט DD/MM/YYYY כנהוג במערכת.
