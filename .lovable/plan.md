# לוג הרשאות לביקורת מערכות מידע

## מה ייבנה
1. **רישום אוטומטי של כל שינוי הרשאה** — מרגע ההפעלה, כל פעולה כזו נשמרת ולא ניתנת לעריכה או מחיקה:
   - הוספה / הסרה של תפקיד למשתמש (מנהל, HR, שכר, תפעול וכו').
   - מתן / ביטול גישה לחברה.
   - יצירת משתמש, השבתה, חסימה והפעלה מחדש.
   - שינוי גישות דיגיטליות של עובד (מערכות, הרשאות במערכות חיצוניות).
   לכל רישום: תאריך ושעה, מי ביצע, על מי, מה השתנה (לפני ← אחרי), חברה.
2. **מסך „לוג הרשאות"** בהגדרות (מנהל מערכת וראשי בלבד):
   - סינון לפי טווח תאריכים, משתמש, מבצע, סוג פעולה.
   - **ייצוא לאקסל** ו-**PDF חתום בתאריך הפקה** להגשה לביקורת.
3. **דוח „תמונת מצב הרשאות נוכחית"** — מי מחזיק איזה תפקיד ובאיזו חברה ברגע זה, גם לייצוא לאקסל. (מבקרים מבקשים בדרך כלל את שניהם.)

## חשוב לדעת
- שינויים שבוצעו **לפני** ההפעלה לא נשמרו במערכת, ולכן הלוג יתחיל מהיום. תמונת המצב הנוכחית תהיה מלאה.
- אף משתמש, כולל מנהל ראשי, לא יוכל למחוק או לשנות רישומים.

## פרטים טכניים
- טבלה חדשה `permission_audit_log` (append-only: RLS ל-SELECT למנהלים בלבד, ללא UPDATE/DELETE).
- טריגרים security definer על `user_roles`, `user_company_access`, `digital_access` ושינוי סטטוס גישה — רישום אוטומטי עם `auth.uid()` כמבצע, גם כשהשינוי מגיע מפונקציית `manage-users`.
- בפונקציית `manage-users` להעביר את מזהה המבצע כדי שיירשם נכון (שימוש ב-service role).
- מסך חדש בהגדרות + `exportToExcel` הקיים + PDF בעברית מהספרייה הקיימת.
