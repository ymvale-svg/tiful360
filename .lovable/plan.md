# דוח נוכחות חודשי לעובד – בדיקה, תיקון ואישור

## מה כבר קיים היום
- עובד יכול לתקן שעת החתמה בעצמו עד 3 פעמים בחודש (המערכת חוסמת את התיקון הרביעי).
- קיימות בקשות תיקון שמנהל מאשר או דוחה, ואחרי אישור השעה מתעדכנת אוטומטית.

## מה ייבנה

### 1. תיקון רביעי ואילך הופך לבקשה עם נימוק
- בשלושת התיקונים הראשונים בחודש העובד מתקן לבד, בלי נימוק (כמו היום).
- מהתיקון הרביעי והלאה, במקום הודעת חסימה, ייפתח לו טופס "בקשת תיקון" עם **נימוק חובה**.
- הבקשה מגיעה אלייך. את מאשרת או דוחה, ובאישור השעה מתעדכנת אוטומטית.
- העובד יראה כמה תיקונים עצמיים נשארו לו החודש.

### 2. מסך מרוכז אחד: "דוחות נוכחות חודשיים"
מסך אחד בעמוד השכר, לחודש שבוחרים:
- רשימת כל העובדים עם מצב הדוח: לא נשלח / נשלח לעובד / העובד אישר / ממתין לבקשות תיקון / אושר סופית.
- לכל עובד: מספר ימים חסרים (ימי עבודה בלי החתמה או עם החתמה חסרה), **בלי** לספור חופשה, מחלה, מילואים, חל"ת, חגים, חול המועד ושבתות.
- כפתור "שלח דוח לעובד" לעובד אחד, וכפתור "שלח לכל מי שיש לו חוסרים".
- רשימת כל בקשות התיקון הממתינות במקום אחד, עם "אשר" / "דחה" לכל אחת וגם **"אשר הכול"**.
- כפתור "אשר דוח" לכל עובד בסוף התהליך.

### 3. הדוח לעובד (מסמך מסודר ויפה)
- כותרת עם לוגו החברה, שם העובד, מספר עובד וחודש.
- טבלה של כל ימי העבודה בחודש: תאריך, יום, כניסה, יציאה, סה"כ שעות. בימי היעדרות תופיע הסיבה (חופשה / מחלה / מילואים וכו').
- ימים חסרים מודגשים בצבע, וסיכום בראש הדוח: ימי עבודה, ימי היעדרות, ימים חסרים.

### 4. שליחה במייל וכניסה לאזור האישי
- העובד מקבל מייל עם הדוח מצורף (לפי הכלל: קבצים מצורפים ולא קישורים) וכפתור כניסה לאזור האישי.
- באזור האישי הוא רואה את אותו הדוח, משלים חוסרים ומתקן שעות – לפי אותו כלל של 3 תיקונים חופשיים ואחר כך בקשה עם נימוק.
- בסיום הוא לוחץ "אישרתי את הדוח", ואת מקבלת הודעה.
- את מאשרת את הדוח סופית (אחד-אחד או "אשר הכול").

## פרטים טכניים
- שינוי בפונקציית התיקון העצמי: במקום לזרוק שגיאה בתיקון הרביעי, הלקוח פותח בקשת תיקון; נימוק חובה ייאכף גם בבסיס הנתונים לבקשות שמעבר למכסה.
- טבלה חדשה לדוחות חודשיים לעובד (חברה, עובד, חודש, מצב, תאריכי שליחה/אישור עובד/אישור סופי) עם הרשאות לפי חברה, ועובד רואה רק את שלו.
- חישוב ימי עבודה יתבסס על הלוגיקה הקיימת של טבלת הנוכחות החודשית (ימי עבודה של העובד, חגי החברה, היעדרויות מאושרות).
- פונקציית שרת חדשה ששולחת את מייל הדוח לעובד אחד בכל פעם, עם קובץ PDF מצורף, בעיצוב המיילים האחיד.
- "אשר הכול" משתמש בפעולת האישור הקיימת לכל בקשה ברשימה.
- בדיקות: תיקון רביעי דורש נימוק; ספירת חוסרים לא כוללת חופשה/חגים/שבתות; אישור בקשה מעדכן את השעה.
