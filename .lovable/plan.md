# תפריט קליק ימני רוחבי במערכת

## העיקרון
לחיצה ימנית על פריט במערכת (שורה בטבלה, כרטיס, שם עובד) פותחת תפריט קצר עם הפעולות הרלוונטיות לאותו פריט, לפי ההרשאות של המשתמש. במקומות שאין בהם תפריט מותאם, הדפדפן ממשיך להציג את התפריט הרגיל שלו (העתקה, הדבקה וכו'), כדי שלא נחסום פעולות מוכרות.

## תפריט לפי מיקום
| מיקום | פעולות |
|---|---|
| שורת עובד (רשימת עובדים, וכל מקום שבו שם עובד מופיע כקישור) | פתח תיק עובד, פתח בלשונית חדשה, העתק שם / ת.ז. / טלפון / מייל, ערוך פרטים*, צור קריאת שירות לעובד |
| שורת פריט במשאבים (כל הדומיינים) | פתח כרטיס פריט, פתח בלשונית חדשה, ערוך*, בצע מסירה / הזדכות (רק כשרלוונטי לפריט), חדש תוקף (רק לפריטים עם תאריך תפוגה), העתק קוד / מס' סידורי / רישוי, מחק* |
| כרטיס קטגוריה / תת-קטגוריה | פתח, הוסף פריט לתת-קטגוריה, ערוך שם*, העבר לדומיין אחר* |
| קריאת שירות | פתח, שנה סטטוס, שייך לאחראי, העתק מס' קריאה, פתח תיק עובד |
| בקשת חופשה / תיקון נוכחות | אשר, דחה, פתח תיק עובד |
| מסמך (מסמכי פריט / עובד) | פתח, הורד, העבר לארכיון / שחזר, מחק* |
| תהליך קליטה | פתח תהליך, פתח תיק עובד, פתח קריאת שירות מקושרת |
| פרוטוקול / טופס ממתין לחתימה | פתח, שלח שוב קישור חתימה, העתק קישור, הורד PDF חתום |
| מנוי רכב | ערוך, שנה סטטוס, פתח תיק עובד |
| פריט בתפריט הצד | פתח בלשונית חדשה |

\* מוצג רק למשתמשים בעלי הרשאה לפעולה. פעולה שאינה מותרת לא תוצג כלל (ולא תוצג באפור).

## התנהגות
- התפריט נפתח מימין לשמאל ובעברית, ומיושר לעיצוב הקיים (כולל מצב כהה).
- פעולות מסוכנות (מחיקה) מופרדות בקו ובצבע אזהרה, ותמיד מבקשות אישור.
- "העתק" מציג הודעה קצרה "הועתק".
- נגישות: קיצור Shift+F10 ומקש התפריט במקלדת פותחים את אותו תפריט על השורה המסומנת, וניתן לנווט בחצים.
- טלפון וטאבלט: לחיצה ארוכה פותחת את אותו תפריט.
- כל הפעולות בתפריט הן פעולות שכבר קיימות במסכים, כך שאין התנהגות חדשה, רק דרך מהירה להגיע אליה.

## שלבי ביצוע
1. רכיב משותף אחד לתפריט, שמקבל רשימת פעולות ומסנן אותן לפי הרשאות.
2. ספריית פעולות לכל סוג פריט (עובד, נכס, קריאה, מסמך וכו') שמפעילה את הדיאלוגים והניווטים הקיימים.
3. חיבור לפי סדר שימוש: עובדים, משאבים, קריאות שירות, ולאחר מכן מסמכים, חופשות ונוכחות, קליטה, פרוטוקולים, מנויים ותפריט הצד.
4. בדיקה על כל מסך, עם עכבר, מקלדת ומובייל, ולפי תפקידים שונים.
